# Security Policy

## Reporting a Vulnerability

For any abuse reports or security concerns, please open an issue in this repository.

We take all reports seriously and will respond within 48 hours.

## Scope

This tool performs static recompilation of game code and assets. It does not:
- Distribute copyrighted game files
- Bypass encryption or DRM
- Access network resources
- Collect telemetry

All processing happens locally on your PC using your own legal game copy.
